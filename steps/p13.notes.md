# P13 causal extraction pilot (research, store copy only)

Scripts: steps/p13_extract.py (extract + write CAUSES edges into a COPY), steps/p13_judge.py (30-sample precision).
Private outputs (chat content) stay outside the repo: /root/p13/out/{edges.jsonl,judged.json,extract_summary.json}.

Setup: 100 random conversations (seed 1313, 8..60 facts, 299 eligible of 820), 2054 facts. Extractor
deepseek-v4.1-flash temp 0, strict prompt; pair = (cause fact id -> effect fact id), plane CAUSAL, label CAUSES.
Result: 79 edges in 41/100 conversations (52 explicit, 27 implicit). 76/100 replies parsed; 20 replies came back
empty even after the retry ladder, so those conversations count as "no edges" (recall is not measured here).
Judging: 30 random edges (seed 1314), judge sees only the two facts + source messages, not the extractor's basis.

Precision (primary judge claude-sonnet-5.5): 20/30 = 0.667 (Wilson 95% CI 0.49-0.81); 8 not_causal, 2 unjudged
(empty judge reply, counted as misses; 20/28 = 0.71 if dropped), 0 reversed.
Second judge gpt-4.1-mini: 28/30 = 0.933 (far more lenient); both agree causal 19/30 = 0.633; agreement 0.667.
Explicit 13/21 = 0.62, implicit 7/9 = 0.78 (small n, no difference to claim).

Good: "court allows the other parent to relocate the child -> user has to quit a 16-year job";
"user is a big guy -> will take whatever dose is needed for the injury"; "agent stopped working -> wipes the VPS".
Bad: restatement of the same belief ("CPU process is flawed" -> "there has to be a better way");
a symptom as a "consequence" of its own injury; a precondition ("could not buy X yet" -> "plans to add X").

Verdict: ~2/3 precision, too low to feed typed_walk or the live graph without a second-stage verifier; the failure
modes are restatement and precondition-vs-reason. Nothing written to the live store (athena.mpmf mtime/size
identical before/after); the 79 edges exist only in /root/p13/athena_p13.mpmf.
