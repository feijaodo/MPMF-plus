# p18 - second-pass retrieval (RESEARCH, flag `second_pass`, default OFF)

## What it is
- `src/mpmf_plus/second_pass.py`; wired in `hermes_adapter.py` (`get_tool_schemas`, `handle_tool_call`, `prefetch`).
- Flag off: tool schema/handler byte-for-byte as before (tests/test_p18_second_pass.py pins it).
- Flag on: `mpmf_recall(query)` returns the prefetch rendering (`## [id] name` + text, same caps / history ordering),
  only memories NOT already in this turn's prefetch block or earlier second-pass calls, <= `second_pass_max_calls` (2)
  per turn (reset by the next prefetch), refusal/"no new memories" are said in plain text; a failed recall raises.
  Tool description tells the model to call it before answering/declining with a re-worded, specific query.
- Config: second_pass false, second_pass_max_calls 2, second_pass_k 6 (`MPMF_<KEY>` env works).

## Measurement (steps/p18_eval.py, p18_analyze.py; TUNE p6 98 q, md5 2e4c8513 unchanged; store = copy of live athena)
Same prefetch block per question for all arms; answer model = scorecard's (deepseek-v4.1-flash, tool-calling, <=3 rounds),
scorecard prompt, 3 judges, majority, tie->partly. Arms: off (no tool), oldtool (shipped mpmf_recall, flag off), on (new).
Two complete runs (answer sampling at temperature 0 still differs between runs):
- run1: off 0.434 (38 strict) | oldtool 0.520 (46) | on 0.510 (44); off->on +7.7 pts, strict 8/2 p=0.109, correct-or-partly 12/3 p=0.035
- run2: off 0.424 (35) | oldtool 0.526 (43) | on 0.510 (44); off->on +8.7 pts, strict 11/2 p=0.022, correct-or-partly 11/3 p=0.057
- on vs oldtool: -1.0 / -1.5 pts, strict 2/4 p=0.69 and 2/1 p=1.0 -> no difference.
- Reading: giving the model a lookup tool helps (declined 34-38 -> 23-25), but the tool that is already shipped gets all of
  it. The new dedupe/rendering/limit adds nothing measurable on TUNE. Verdict: EFFECT=no_effect, flag stays off.
- Caveats: the eval answer model is deepseek flash, not the live agent model; TUNE questions are generated from single raw
  messages (source text sits in the prefetch block for only 1/98, so the tool is used on near-misses); the tool is used on
  ~57% of questions with ~1 s extra round trip (tool itself ~0.37 s). HOLDOUT/LOCKED untouched.
- Cost: ~$0.19 per run of three arms.
