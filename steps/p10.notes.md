# p10 — behavioural scorecard
- src/mpmf_plus/eval/behaviour.py: 30 tasks (10 claim / 10 repeat / 10 numbered) on a deterministic mock sandbox.
  Scoring is a pure function of the transcript: tool calls are REPLAYED on a fresh sandbox (state/failures re-derived, tool output in the transcript is not trusted).
- Flags: no_tool_claim (final message with zero tool calls), false_claim (claims done, items unmet), finished_incomplete, no_final, repeat_violation (identical call re-issued after it failed with no state-changing success in between; flaky-tool task r05 exempt, outage tasks r06/r07 allow 1).
- `--system-extra` is the hook p11 uses (off = baseline). `--score-only FILE` re-scores without a model.
- Baseline (anthropic/claude-sonnet-5.5, temp 0, 105 calls, $0.42): 30/30 pass. NO headroom: p11 cannot show an improvement on these tasks with this model.
- First run (discarded, kept as baseline_v0_discarded.*): 29/30; the one fail (r04) and many wasted calls were the mock shell rejecting ordinary composition (`cd x && ls`, `| tail`). That is a sandbox bug, not agent behaviour, so the shell was fixed and everything re-run. Fix made after seeing results — disclosed.
- Tests: tests/test_behaviour.py (11, scripted agents, no model). tests/test_scripts.py::test_host_contract fails in this shell (no `agent` module); fails identically with p10 files stashed; deploy gate OK.
