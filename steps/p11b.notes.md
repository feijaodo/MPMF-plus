# p11b — lessons OFF vs ON on the frozen set (attempt 2, VALID)

Design (written before the runs): deepseek/deepseek-v4.1-flash, all 38 frozen tasks, one trial per task per
arm, OFF first then ON, fresh runs, temperature 0, same system prompt, max_tokens 1500, 4 workers. Step cap
60 model calls in BOTH arms (the repo default is 14; see Cause). The arm sets the flag in its own process
environment (config file = empty temp file), reads it back through paths.load_config before the first task
and refuses to run on a mismatch (guard checked: forcing the wrong value exits with REFUSE). OFF read back
false on 38/38 rows, ON read back true on 38/38 rows. No repo code, frozen file, scorer or hook was edited;
glue lives outside the repo. Frozen file md5 ba5efabd6df3d8f16232675028e5b2e2 (matches p10b), mode 444.
Each arm ran in one process, no crash, no resume. Nothing was re-run after seeing a result.

## Cause of the first attempt's INVALID
The hook fires at the model's first completion claim (a message without a tool call). With the 14-call cap,
24 of 38 ON tasks hit the cap while still calling tools, so no claim and no lesson event. Fix, glue only:
the step cap is raised to 60 for both arms, so a task can reach its claim. The first attempt's numbers
are not used here.

## Validity (rule 4)
ON tasks with a lesson event carrying its text: 38 of 38. OFF transcripts with a lesson event: 0 of 38.
Lesson shown at model call 4..45 (median about 18).

## Numbers (38 tasks per arm)
OFF: passes 12/38 = 0.316, Wilson 95% [0.191, 0.475]; errors 0, timeouts 0; no final message 0
ON : passes 17/38 = 0.447, Wilson 95% [0.301, 0.603]; errors 0, timeouts 0; no final message 0
McNemar exact: b (OFF fail, ON pass) = 9, c (OFF pass, ON fail) = 4, p = 0.2668 (both pass 8, both fail 17)
EFFECT = no_effect (needs p < 0.05 and b > c; b > c but p = 0.27). Flag lessons_at_action stays OFF.

## Notes
- Cost (tokens x list price): OFF about $0.32, ON about $0.46.
- ON is not a pure lesson effect: ON used more model calls and tokens on average, and the lesson gives
  one extra step after the claim. Not separated here.
- The selection run is not an arm. For context only (selection run, not an arm): the kept set passed 11/114
  = 9.7% there, under the 14-call cap.
- Both arms ran under the 60-call cap, so these rates are not comparable with any 14-call run.
