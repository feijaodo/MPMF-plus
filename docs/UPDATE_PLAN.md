## 0. Universal preconditions

1. Back up the instance directory and record md5s:
   `cp -a <instance> <home>/.host/backups/pre-pkg-<UTC>/` and `md5sum -c` afterwards.

## 1. Core library — `<core>/mpmf/` (canonical, live)

- **Used by:** the live gateway process (through `live_memory`), pid started 2026-10-27 11:05:50Z.
- **Risk:** highest — this is the code the live agent runs.
- **Steps:**
  1. `cp -a <core> <home>/.host/backups/pre-pkg-<UTC>/mpmf`
  2. Diff the release `src/mpmf/` against `<core>/mpmf/`; expect only the two cosmetic
     docstring changes verified in Round 59b (`query.py`, `__init__.py`).
  3. Copy the release `src/mpmf/*.py` over the canonical tree (keep `ingestion/` — already identical).
  4. `python3 -c "import mpmf; print(mpmf.__version__)"` and run the suite against a temp store.
- **Restart:** the gateway must be restarted for the change to load (Python modules are cached
  per process). Restart is **the author's** action, not the agent's.
- **Rollback:** restore the backup directory and restart again; no store migration is involved,
  the on-disk format is unchanged.

1. Build copy (2) — trivial, proves the copy procedure.
2. Ayu mirror (3) — no gateway involvement.
3. Wrapper twins (4) → plugin (5) — do these together, one restart.

and the md5 record updated in `CHANGES/manifest.md`.
